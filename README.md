# Kural test vocals

Real singing recordings used to test Kural's pitch analysis and pitch shifting.
Generated by `tools/testdata/fetch_vocals.py` on `main` (workflow "Fetch test vocals").
See ATTRIBUTION.md for sources and licences, manifest.csv for the track list.

- `audio/*.flac`: 16-bit mono
- `f0/*.csv`: reference pitch (`time_s,f0_hz`, 0 = unvoiced) where the dataset has one
